# Аналитика в Vercel

Код подготовлен для Vercel Web Analytics на Pro / Enterprise. В проекте Vercel откройте **Analytics → Enable**, затем выполните новый deployment. До включения и публикации события в панели не появятся. Установка npm-пакетов не требуется; сборка из `vercel.json` копирует только публичные файлы лендинга в `public`.

Эти же данные можно смотреть на адресе сайта `/analytics`. Раздел и его API закрыты серверной авторизацией. Настройка переменных Vercel и значения столбцов описаны в [ANALYTICS-DASHBOARD.md](ANALYTICS-DASHBOARD.md).

Скрипт `analytics.js` загружает `/_vercel/insights/script.js` асинхронно. Автоматический просмотр корневой страницы отключён: каждый экран отправляет собственный просмотр. Ошибка загрузки аналитики не мешает переходам, выбору карточек и получению итоговой ссылки.

## Какие данные собираются

| Данные | Где смотреть в Vercel | Содержимое |
| --- | --- | --- |
| Просмотр экрана | Pages: `/onboarding/1` … `/onboarding/5` | Один просмотр при входе на видимый экран; прямые ссылки `#1`–`#5` учитываются |
| Основная кнопка | Events → `cta_click` | `screen`: 1–5; на экранах 2 и 4 также `choice`, включая принятие первоначально выбранной карточки |
| Видимое время на экране | Events → `screen_time_1` … `screen_time_5` | `duration_ms`: миллисекунды; `duration_bucket`: диапазон времени |
| Women / Men / Both | Events → `preference_select` | `value`: Women, Men или Both; явные действия мышью, касанием и клавиатурой |
| Типаж на экране 4 | Events → `type_select` | `value`: Karolina, Hanna, Helen или Laura |
| Гео | Country | Vercel определяет страну посетителя и позволяет фильтровать просмотры и события по стране |

`/onboarding/N` — виртуальные адреса только для аналитики: реальные URL сайта, hash-навигация и параметры итоговой ссылки сохраняются. На пятом экране событие кнопки учитывает отправку формы, в том числе Enter. Отключённые камера, микрофон, чат, Terms и Privacy Policy не создают событий клика.

В каждом событии не более двух пользовательских свойств — это соответствует обычному Pro, без требования Web Analytics Plus.

## Как измеряется время

Учитывается только время, когда вкладка видима. Завершённый отрезок отправляется при переходе на другой экран, скрытии вкладки, уходе со страницы и перед переходом на итоговый сайт. Возврат из фоновой вкладки начинает новый отрезок, но не повторяет просмотр экрана. Восстановление страницы из браузерного кеша после возвращения на сайт учитывается новым просмотром.

Каждый отрезок отправляется один раз: это разница времени, а не накопительный снимок. Поэтому повторные `visibilitychange` / `pagehide` не удваивают длительность. Если пользователь переключал вкладки, одному просмотру могут соответствовать несколько отрезков; сумма их `duration_ms` даёт видимое время на этом экране. Фоновое ожидание не учитывается.

Диапазоны: `<5s`, `5-15s`, `15-30s`, `30-60s`, `1-2m`, `>=2m`. В Events можно выбрать конкретный экран и посмотреть распределение по `duration_bucket`, а затем фильтровать по стране. Для числового `duration_ms` Vercel показывает значения как свойства событий; автоматическое среднее время в штатной панели не настроено.

## Настройки и проверка после публикации

`config.js` содержит `analytics: { enabled: true }`. Значение `false` выключает аналитику. На localhost, 127.0.0.1, ::1 и при открытии HTML-файла с диска скрипт сбора не загружается, чтобы локальные проверки не попадали в статистику.

После включения Analytics и deployment откройте опубликованный адрес, пройдите пять экранов и проверьте запросы `/_vercel/insights/*`, страницы `/onboarding/N` и события в панели. В Vercel отдельно выбираются Production и Preview; это позволяет отделить проверочные визиты от основного трафика. При блокировке скрипта браузером или закрытии страницы до его загрузки доставка событий не гарантируется.

Email, `myfdata`, `subid`, `p7`, `clickid`, `subid2` и итоговая ссылка не передаются в пользовательских свойствах аналитики. `beforeSend` удаляет query и hash из URL событий. Передача параметров в конечный адрес через `redirect.js` продолжает работать отдельно.
